A.1 The Multiple Linear Regression Model

Simple linear regression (SLR) uses one explanatory variable. As soon as we believe two or more factors jointly drive the outcome, we move to multiple linear regression (MLR).

Geometrically, SLR fits a line through a 2-D scatter. MLR with two predictors fits a plane through a 3-D scatter. With k > 2 predictors the fitted surface is a hyperplane — we can't draw it, but the algebra is identical.

Population Model (the true, unknown equation)
Y = β₀ + β₁x₁ + β₂x₂ + … + βₖxₖ + ε
  • Y — the dependent (response, outcome) variable.
  • x₁ … xₖ — k explanatory (independent, predictor) variables.
  • β₀ — the intercept.
  • β₁ … βₖ — the slope coefficients (one per predictor).
  • ε — the random error term, capturing everything not explained by the x's.
Key idea — "Linear in the parameters"

The word linear does not mean the relationship between Y and x must be a straight line. It means the model is linear in the parameters β. You can include x², ln x, or x·D as regressors and the model is still "linear" — because the β's enter linearly. This is crucial for Section A.2.

The two parts of the model

  • Systematic part: β₀ + β₁x₁ + … + βₖxₖ = E(Y|x) — the average value of Y given a specific combination of x-values.
  • Random part: ε — the individual deviation of each observation from that average. σ = SD(ε) is called the standard error of the model and measures typical prediction error.

The 5 Classical Assumptions (MEMORISE)

The Gauss–Markov Assumptions (A1–A4) + Normality (A5)
#AssumptionWhat it means in plain languageWhat breaks if it fails
A1 E(ε) = 0 for every x The regression surface passes through the average of Y at every point. No systematic over- or under-prediction. Biased estimates — your b's don't converge to the true β's.
A2 Var(ε) = σ² (constant) Homoskedasticity: the spread of errors around the regression surface is the same for all values of x. Think of uniform "bands" above and below the plane. OLS is no longer BLUE; standard errors are wrong — tested in D.3.
A3 Cov(εᵢ, εⱼ) = 0 (i ≠ j) No autocorrelation: knowing that observation 5 is above the plane tells you nothing about whether observation 6 will also be above it. Critical for time-series data. OLS is no longer BLUE; standard errors are wrong.
A4 x's non-random AND no exact linear relation among x's No predictor can be written as a perfect linear combination of the others (no exact multicollinearity). Also, x is not correlated with ε (no endogeneity). If exact MC: model cannot be estimated at all. If endogeneity: OLS is biased. If quasi-MC: see D.2.
A5 ε ~ Normal(0, σ²) The errors are normally distributed. This is needed to justify t- and F-tests in small samples. By the Central Limit Theorem, large samples make this assumption less critical. t- and F-tests are only approximate in small samples; checked with Q-Q plot in D.1.
Deeper explanation — why A1 implies E(Y|x) = β₀ + β₁x₁ + … + βₖxₖ

If E(ε) = 0, then taking expectations of both sides of the model:

E(Y|x) = β₀ + β₁x₁ + … + βₖxₖ + E(ε) = β₀ + β₁x₁ + … + βₖxₖ

This is why the systematic part is the conditional mean of Y. The error ε is the individual's departure from that mean — it averages to zero by assumption.

Interpreting the Parameters

Interpretation template (use exactly this language in the exam)

β₀ (intercept): The expected (average) value of Y when all explanatory variables simultaneously equal zero. Often not economically meaningful (a price of $0 makes no sense), but we keep the intercept regardless — dropping it forces the regression plane through the origin and can severely distort all other estimates.

βᵢ (slope of xᵢ): A one-unit increase in xᵢ is associated with a change of βᵢ units in the expected value of Y, ceteris paribus — holding all other explanatory variables constant.

Why "ceteris paribus" matters: In SLR you can't hold anything constant because there's only one x. In MLR, each slope isolates the partial effect of one variable while mathematically controlling for the rest. This is what makes regression so powerful compared to simple correlations.

Hamburger Chain — Parameter Interpretation

Suppose SPSS estimates: Sales = 118.9 − 7.91·Price + 1.86·Advert

  • b₀ = 118.9: If both Price = 0 and Advert = 0, expected Sales = 118.9 (×1000 $). Not realistic, but mathematically necessary.
  • b₁ = −7.91: Each extra dollar on the burger price is associated with a decrease of $7,910 in expected monthly sales, holding advertising fixed. The negative sign matches economic intuition (demand law).
  • b₂ = 1.86: Each extra $1,000 spent on advertising is associated with an increase of $1,860 in expected monthly sales, holding price fixed.
Common Pitfalls
  • "Association" not "causation": Regression coefficients measure statistical association. Without a randomised experiment, you cannot claim that changing x causes Y to change.
  • Units matter: If you double the unit of xᵢ (e.g. from grams to kilograms), bᵢ halves. Always state units when interpreting.
  • Don't omit the intercept unless you have a compelling theoretical reason. The intercept absorbs the mean of ε and keeps residuals centred at zero.
A.2 Non-Linear Relationships — Transformations

Many real-world relationships are not straight lines: diminishing returns, exponential growth, U-shaped cost curves. Because MLR is linear in the parameters (not necessarily in the variables), we can capture these shapes by transforming Y and/or x before entering them into the regression.

Key rule — choose the transform based on theory, not R²

Ask: what economic story do I expect? Diminishing returns → polynomial or log. Constant elasticity → log-log. Percentage effects → log-linear. Never pick a transform just because it raises R².

The Three Log Models — Interpretations Must Be Memorised

Model nameEquationInterpretation of β₁When to use
Log-log (double-log / log-linear in both) ln Y = β₀ + β₁ ln x + ε A 1% change in x leads on average to a β₁ % change in Y. β₁ is an elasticity. Demand and production functions where both variables grow proportionally.
Log-linear (semi-log, log on Y) ln Y = β₀ + β₁ x + ε A one-unit increase in x leads on average to approximately a β₁ × 100 % change in Y. Exponential growth/decay; wage equations where the % return to an extra year of schooling is roughly constant.
Linear-log (semi-log, log on x) Y = β₀ + β₁ ln x + ε A 1% change in x leads on average to approximately a β₁ / 100 unit change in Y. Relationships with diminishing absolute returns to x (e.g. income and expenditure).
Deeper explanation — where do these interpretations come from?

Log-log: Differentiate both sides w.r.t. x. Since d(ln Y)/dx = (1/Y)·(dY/dx), rearranging gives dY/Y = β₁·(dx/x), i.e. the percentage change in Y equals β₁ times the percentage change in x. That is precisely the definition of an elasticity.

Log-linear: Differentiate w.r.t. x: d(ln Y)/dx = β₁ → (1/Y)·(dY/dx) = β₁ → dY/Y ≈ β₁·dx. So a one-unit change in x changes Y by approximately 100·β₁ percent.

Linear-log: Differentiate w.r.t. x: dY/dx = β₁·(1/x) → dY = β₁·(dx/x) = β₁ × (% change in x / 100). So a 1% change in x changes Y by approximately β₁/100 units.

The "approximately" caveat: these are calculus (infinitesimal) approximations. For large discrete changes, the exact formula differs. On the exam, always state the approximate version.

Example — Wage Elasticity

Suppose you estimate: ln(Wage) = 0.5 + 0.08·Education + ε (log-linear)

Interpretation: each extra year of education is associated with approximately an 8% increase in average wages, ceteris paribus. This is the classic Mincer wage equation.

Polynomial Models

A polynomial adds x² (and possibly x³, …) as a separate predictor. The key insight is that the marginal effect of x on Y is no longer constant — it changes as x changes.

Quadratic (Polynomial) Model — Hamburger Example
Sales = β₀ + β₁ Price + β₂ Advert + β₃ Advert² + ε

The marginal effect of Advert on Sales is found by partially differentiating:

∂E(Sales) / ∂Advert = β₂ + 2β₃ · Advert

Typical signs: β₂ > 0 (more advertising helps), β₃ < 0 (diminishing returns — each extra dollar buys less and less sales).

Hamburger numbers — computing marginal effects

Suppose β₂ = 12.15 and β₃ = −2.77.

  • At Advert = $500: marginal effect = 12.15 + 2·(−2.77)·0.5 = 12.15 − 2.77 = 9.38 ($9,380 extra sales per extra $1,000 advertising). Very profitable.
  • At Advert = $2,000: marginal effect = 12.15 + 2·(−2.77)·2 = 12.15 − 11.08 = 1.07. Still positive, but barely worth it.

The turning point (maximum sales) is at Advert* = −β₂ / (2β₃) = −12.15 / (2×−2.77) ≈ $2,193. Spending more than that actually decreases expected sales.

Pitfalls with transformations
  • Collinearity from polynomial terms: Advert and Advert² are highly correlated by construction. This inflates standard errors (Chapter D.2). Centering Advert before squaring it (i.e. using (Advert − mean) and (Advert − mean)²) reduces this problem.
  • Log of zero or negative values: ln(0) is undefined. Never take log of a variable that includes zeros without first checking. Common fix: use ln(x + 1).
  • R² is not comparable across transformations of Y: You cannot compare the R² of a linear model (Y = …) with that of a log-linear model (ln Y = …) because the dependent variable is different in each.
  • Use ln, not log₁₀ in SPSS: The economic interpretations above are derived using natural logarithms. SPSS's LN() function is correct; LOG() gives base-10.
A.3 Dummy Variables — Handling Qualitative Predictors

When Do You Need a Dummy?

Many important predictors are qualitative: gender, country, education level, season, brand. They have no natural numeric scale. Even if categories are encoded as numbers (1 = master, 2 = bachelor, 3 = high school), those codes imply false distances and a false ordering. You must recode qualitative variables into dummy (0/1 indicator) variables before regression.

The dummy variable rule

For a qualitative variable with M categories, create exactly M − 1 dummies. The omitted category is the reference group. Its expected outcome is captured by the intercept β₀. Each dummy coefficient measures the difference from that reference group.

Why M − 1, not M? If you created M dummies, their sum would equal 1 for every observation — a perfect linear combination of the intercept column. This is exact multicollinearity, making estimation impossible. This is called the dummy variable trap.

Two-Category Case (M = 2)

House Price Model with Neighbourhood Dummy
PRICE = β₀ + β₁ SQFT + β₂ D + ε

where D = 1 if the house is in a desirable neighbourhood, D = 0 otherwise (= reference group).

Splitting by D:

  • D = 0: E(PRICE) = β₀ + β₁ SQFT
  • D = 1: E(PRICE) = (β₀ + β₂) + β₁ SQFT

Interpretation of β₂: A house in the desirable neighbourhood has an average price β₂ units higher than an otherwise equivalent house (same size) outside it. Graphically: two parallel lines with the same slope β₁ but vertically separated by β₂.

Intuition — the dummy shifts the intercept, not the slope

Without the dummy, you would fit a single line through both groups, and the slope would be a mixture of both groups' slopes. Adding the dummy lets the model recognise that the two groups have different "base levels" of the outcome, while assuming the relationship between SQFT and PRICE has the same steepness in both groups. If the slopes should also differ, you need an interaction (Section A.4).

Multiple-Category Case (M > 2)

Diploma Example — 3 Education Levels

Categories: Master, Bachelor, High School. We choose High School as reference.

  • D_B = 1 if Bachelor, 0 otherwise
  • D_M = 1 if Master, 0 otherwise
  • High school: D_B = D_M = 0
Y = β₀ + β₁X₁ + β₂D_B + β₃D_M + ε

Reading the coefficients:

  • β₂ = average difference in Y between a Bachelor and a High-School graduate, holding X₁ fixed.
  • β₃ = average difference between a Master and a High-School graduate, holding X₁ fixed.
  • β₃ − β₂ = average difference between a Master and a Bachelor. (Not directly estimated; compute from output.)
  • Graphically: three parallel lines with equal slope β₁, shifted vertically by 0, β₂, and β₃ respectively.
Choosing the reference category

Technically, any category can be the reference — the model fit is identical. Strategically, choose the reference that makes coefficients most interpretable. Common choices:

  • The largest group (gives more stable estimates for the reference mean).
  • The natural baseline (e.g., "no treatment" in a medical study, "secondary education" in a wage study).
  • Avoid choosing a very small group as reference — the intercept becomes imprecisely estimated.
SPSS — Creating Dummy Variables
  1. Transform → Create Dummy Variables (easiest; select the categorical variable, SPSS generates M − 1 dummies automatically, choosing the last category as reference by default).
  2. Alternatively, Transform → Recode into Different Variables to manually define each dummy.
  3. Place all M − 1 dummies (not the original categorical variable) in Analyze → Regression → Linear → Independent(s).
  4. Inspect the Coefficients table: each dummy's b coefficient is the difference from the reference group.
A.4 Interaction Variables

When Do You Need an Interaction?

Key idea — when the effect of one variable depends on another

A dummy variable shifts the intercept: all groups have the same slope. An interaction variable allows the slope itself to differ by group (or by the value of another variable).

Visual diagnostic: Plot Y vs x separately for each category. If the lines are clearly not parallel — if the slope of one group is steeper than another — you need an interaction.

Case 1: Quantitative × Qualitative Interaction

House Price — allowing slope to differ by neighbourhood
PRICE = β₀ + β₁ SQFT + β₂ D + β₃ (SQFT × D) + ε

Splitting by D:

  • D = 0: E(PRICE) = β₀ + β₁ SQFT   (slope = β₁)
  • D = 1: E(PRICE) = (β₀ + β₂) + (β₁ + β₃) SQFT   (slope = β₁ + β₃)

Interpretation:

  • β₁ = slope of SQFT in the reference group (undesirable neighbourhood).
  • β₃ = extra slope of SQFT in the desirable neighbourhood. If β₃ > 0, an extra square foot is worth more there.
  • β₂ = vertical gap between the two lines at SQFT = 0 (the "level shift"). Often not meaningful in isolation.
  • Total price difference between groups at a given size: β₂ + β₃ × SQFT — it depends on the house size!
Why you must always include the main effects

When you add the interaction term SQFT × D, you must also include both SQFT and D as separate predictors (the "main effects"). Dropping a main effect forces its coefficient to be zero, which is a restriction not supported by the data. The result is a misspecified model and biased estimates.

Case 2: Qualitative × Qualitative Interaction

Wages by Race × Gender
WAGE = β₀ + β₁ EDUC + δ₁ BLACK + δ₂ FEMALE + γ (BLACK × FEMALE) + ε
GroupExpected Wage (for given EDUC)
White Male (reference)β₀ + β₁ EDUC
Black Maleβ₀ + δ₁ + β₁ EDUC
White Femaleβ₀ + δ₂ + β₁ EDUC
Black Femaleβ₀ + δ₁ + δ₂ + γ + β₁ EDUC

γ is the interaction effect: the extra wage disadvantage (if γ < 0) of being both Black and Female, above and beyond the sum of the two individual disadvantages (δ₁ + δ₂). If γ = 0, the two group penalties are simply additive. If γ ≠ 0, the combination has a multiplicative (synergistic or antagonistic) component.

Case 3: Quantitative × Quantitative Interaction (rare)

Pizza Expenditure — Age × Income
PIZZA = β₀ + β₁ AGE + β₂ INCOME + β₃ (AGE × INCOME) + ε

The marginal propensity to spend on pizza is no longer constant:

∂E(PIZZA) / ∂INCOME = β₂ + β₃ · AGE

If β₃ < 0: older individuals spend a smaller share of each extra dollar on pizza — realistic!

SPSS — Creating an Interaction Term
  1. Transform → Compute Variable: name the new variable (e.g., SQFT_D), then type SQFT * D in the Numeric Expression field.
  2. Click OK — SPSS creates the product variable in the dataset.
  3. Add both the interaction term and the original main effects to the Independent(s) list in the regression dialog.
A.5 Choice of Explanatory Variables

Deciding which variables to include is the most judgment-intensive part of regression. Two types of error have opposite consequences:

Omitted Variable (relevant variable left out)Irrelevant Variable (useless variable included)
Definition A variable that theoretically belongs in the model is excluded. A variable whose true coefficient is 0 is included anyway.
Consequence on bias BIAS: The omitted variable hides inside ε and is correlated with the included x's. Assumption A4 breaks. OLS is no longer BLUE or unbiased. No bias: True coefficient is 0, so estimate is centred on 0.
Consequence on efficiency Standard errors appear small (artificially) because the model doesn't know about the extra noise source. Efficiency loss: Standard errors GROW. Each included variable "uses up" one degree of freedom, leaving less information for the remaining estimates.
Effect on t-tests t-ratios may be inflated — giving false confidence in an estimate that is biased. t-ratios SHRINK — variables that were significant may become non-significant.
Effect on R² R² is artificially low if a relevant variable is missing. R² never falls (adding any variable can only increase or maintain it). Adjusted R² typically falls.
Detection Hard — signs and magnitudes that contradict theory are a warning. Try adding plausible candidates. Easier — fail the 4-question test below.

Sign of the Bias from an Omitted Variable

Omitted Variable Bias Direction
sign(bias of B_in) = sign(β_om) × sign(r(X_in, X_om))
  • β_om = true effect of the omitted variable on Y.
  • r(X_in, X_om) = correlation between the included and omitted variables.
Worked example — Family Income

True model: FAMINC = β₀ + β₁·HE + β₂·WE + ε (HE = husband's education, WE = wife's education)

Misspecified model (omits WE): FAMINC = α₀ + α₁·HE + ε

  • β₂ > 0: wife's education raises family income (positive effect of omitted variable).
  • r(HE, WE) > 0: educated people tend to marry educated partners (positive correlation between included and omitted variables).
  • Bias = (+) × (+) = positive: b₁ overestimates the true β₁ because it wrongly absorbs part of WE's effect.

The 4-Question Test — Should You Add a Variable?

#QuestionVerdict
1Does economic theory or the academic literature say this variable is relevant?Must hold — if theory says no, don't include it regardless of the numbers.
2Is its t-test coefficient significantly different from zero?Yes → keep
3Does adjusted R² increase when the variable is added?Yes → keep
4Do the other coefficients change substantially when this variable is added (suggesting omitted-variable bias)?Yes → keep
Model Selection Pitfalls
  • Adjusted R² is a helpful guide but never the only criterion. Always anchor decisions in theory.
  • Automated selection (forward, backward, stepwise) chooses variables by statistical criteria alone and can produce theoretically absurd models. Treat results as a starting point, not a final answer.
  • Kitchen-sink approach: Throwing every available variable into the regression over-fits the sample, inflates standard errors, and usually produces a model that does not generalise.
  • A wrong sign is a red flag: If a coefficient has the opposite sign from what theory predicts, suspect an omitted variable or multicollinearity.
SPSS — Automated Selection

Analyze → Regression → Linear → Method: choose Forward, Backward, or Stepwise.

Always sanity-check the chosen model against theory before reporting. In an exam, justify each variable with a theoretical argument, not just a p-value.

B.1 Model Fit — The Least Squares Principle

Chapter A gave us the population model. We never observe it directly — we observe a sample of n observations. The job is to estimate the unknown β's using that sample. The estimator used throughout this course is Ordinary Least Squares (OLS / LS).

Population model vs fitted model

Population (unknown, true):

Y = β₀ + β₁x₁ + … + βₖxₖ + ε

Fitted on the sample (what SPSS gives you):

ŷᵢ = b₀ + b₁x₁ᵢ + … + bₖxₖᵢ

Residual: eᵢ = yᵢ − ŷᵢ

The residual eᵢ is the sample equivalent of the unknown error εᵢ. It is what you actually observe after fitting the model.

The Least Squares Objective
Minimise SSE = Σ(yᵢ − ŷᵢ)² = Σeᵢ²

OLS chooses b₀, b₁, …, bₖ to make the sum of squared residuals as small as possible.

Why squared, not absolute?

  • Squaring makes positive and negative residuals both contribute positively (they don't cancel).
  • Squaring penalises large errors more heavily than small ones — a desirable property.
  • The mathematics of minimising a sum of squares leads to closed-form formulas (matrix algebra: b = (X'X)⁻¹X'Y), making computation straightforward.
Geometric intuition

Each observation yᵢ is a point in space. The fitted value ŷᵢ is its projection onto the regression hyperplane. The residual eᵢ is the vertical distance from the point to the plane. OLS tilts and positions the hyperplane to make those vertical distances (squared, summed) as small as possible.

Standard Error of the Model

Estimating σ (the typical error size)
s² = SSE / (n − k − 1)
s = √s²   ← "Std. Error of the Estimate" in SPSS
  • n − k − 1 = degrees of freedom of the residuals. We lose 1 df for the intercept and 1 for each of the k slopes.
  • s estimates the typical prediction error of the model in the original units of Y.
  • In the Hamburger example: if s = 10, the model's predictions are typically off by about $10,000 in monthly sales.
Why divide by n − k − 1, not n?

Dividing by n − k − 1 rather than n makes s² an unbiased estimator of σ². When we use the sample to estimate k + 1 parameters (β₀ through βₖ), we "use up" k + 1 degrees of freedom. What remains (n − k − 1) reflects the independent pieces of information about the error variance. Dividing by n instead would underestimate σ² systematically.

SPSS Output for B.1
  • Coefficients table, column 'B' → the estimated b₀, b₁, …, bₖ.
  • Model Summary, 'Std. Error of the Estimate' → this is s.
  • To save predicted values and residuals: in the regression dialog click Save → Predicted Values: Unstandardized and Residuals: Unstandardized. New columns appear in your dataset.
B.2 Sampling Distribution of the Estimators

The OLS estimators b₀, b₁, …, bₖ are computed from a sample. If we repeated the study with a different sample from the same population, we would get different b's. This means the estimators B₀, B₁, …, Bₖ are random variables with their own sampling distributions.

Distribution of the OLS estimator (under A1–A5)
Bᵢ ~ Normal(βᵢ, se(Bᵢ)²)

Standardising gives the test statistic:

T = (Bᵢ − βᵢ) / se(Bᵢ)   ~   t(n − k − 1)

Under A1–A4 alone (no normality needed): by the Central Limit Theorem, the same t-distribution holds approximately for large n.

The Gauss–Markov Theorem

Gauss–Markov: OLS is BLUE

Under assumptions A1–A4 (no normality required), the OLS estimators are BLUE:

  • Best — they have the smallest variance (most precise) among all linear unbiased estimators.
  • Linear — each bᵢ is a linear function of the y-values.
  • Unbiased — E(Bᵢ) = βᵢ for every i; on average they hit the target.
  • Estimators — of the unknown population parameters β₀, …, βₖ.

What happens if an assumption fails?

  • If A1 fails (wrong functional form or omitted variable): OLS is biased — it no longer hits the target on average.
  • If A2 fails (heteroskedasticity): OLS is still unbiased but no longer "best" (it wastes information) and the reported se's are wrong.
  • If A3 fails (autocorrelation): same as A2 violation — unbiased but not BLUE, wrong se's.
  • If A4 fails (exact MC): OLS cannot even be computed. Quasi-MC inflates se's but leaves estimates unbiased.

What Drives the Size of se(Bᵢ)?

Four ingredients of se(Bᵢ) — examiners love this list
IngredientEffect on se(Bᵢ)Can you control it?
σ — the model's error standard deviation Larger σ → larger se(Bᵢ). More noise in the data makes estimates less precise. No — it reflects inherent randomness in Y not captured by the x's.
sxᵢ — the spread (standard deviation) of xᵢ in the sample More variation in xᵢ → smaller se(Bᵢ). Analogy: you get a more reliable slope estimate if the x-values are spread out. Partially — by experimental design or sampling strategy.
n — the sample size Larger n → smaller se (by a factor of √n). The classic result of increasing precision with more data. Yes — collect more observations.
Correlation between xᵢ and other x's Stronger correlation among predictors → larger se(Bᵢ). This is quasi-multicollinearity (Chapter D.2). Yes — remove or transform redundant predictors.
The VIF formula embedded in se(Bᵢ)

More formally, the variance of bᵢ contains the term 1/(1 − Rᵢ²), where Rᵢ² is the R² from regressing xᵢ on all other predictors. This is exactly the Variance Inflation Factor (VIF) (see D.2). When Rᵢ² → 1 (xᵢ is nearly perfectly predicted by the other x's), se(Bᵢ) → ∞. The estimator exists but is uselessly imprecise.

B.3 Inference About a Single Parameter

Confidence Interval for βᵢ

(1 − α) Confidence Interval for βᵢ
[ bᵢ − tₓ · se(Bᵢ)   ;   bᵢ + tₓ · se(Bᵢ) ]
  • tₓ = critical value from the t-distribution with n − k − 1 degrees of freedom at confidence level (1 − α).
  • For 95% CI and large n: tₓ ≈ 1.96 (two-tailed); for small samples, use the exact t-table.
  • Correct interpretation: "If we repeated this study many times under identical conditions, 95% of the intervals constructed this way would contain the true βᵢ." (The interval is random; the parameter is fixed.)
Confidence interval interpretation trap

Do NOT say "there is a 95% probability that βᵢ lies in this interval." Once the interval is computed from your data, it either contains βᵢ or it doesn't — probability is 0 or 1. The 95% refers to the long-run frequency of the procedure, not to any one interval.

Hypothesis Test on a Single βᵢ

Two-sided t-test: H₀ : βᵢ = 0 vs H₁ : βᵢ ≠ 0
t = bᵢ / se(Bᵢ)   ~   t(n − k − 1) under H₀

Three equivalent decision rules (pick one, all agree):

  1. Critical-value rule: Reject H₀ if |t| > tₓ (where tₓ is the two-tailed critical value).
  2. p-value rule: Reject H₀ if p-value < α. In SPSS, the column labelled 'Sig.' is the two-tailed p-value.
  3. CI rule: Reject H₀ if 0 is NOT contained in the (1 − α) confidence interval for βᵢ.

One-Sided vs Two-Sided Tests

When to use a one-sided test

Use a one-sided alternative when economic theory predicts the direction of the effect before you see the data:

  • H₁ : βᵢ > 0 if theory says xᵢ should have a positive effect on Y.
  • H₁ : βᵢ < 0 if theory says xᵢ should have a negative effect on Y.

Adjustment rule for SPSS (which always prints two-sided p-values):

  1. Check that bᵢ has the sign consistent with H₁.
  2. If yes: one-sided p-value = (SPSS Sig.) / 2.
  3. If no (bᵢ has the wrong sign): you cannot reject H₀ regardless of the p-value — the data contradict the direction of H₁.
Hamburger Chain — Worked t-test

SPSS gives: b₂ = 1.85, se(B₂) = 0.45, n = 75, k = 2.

Test H₀ : β₂ = 0 vs H₁ : β₂ > 0 at α = 5% (one-sided, because advertising should raise sales).

  1. t = 1.85 / 0.45 ≈ 4.11
  2. df = 75 − 2 − 1 = 72; one-sided critical value t₀.₀₅ ≈ 1.67
  3. 4.11 > 1.67 → Reject H₀
  4. One-sided p-value ≈ 0.000 / 2 ≈ 0.000 < 0.05 → same conclusion

Conclusion in plain language: "At a 5% significance level, we reject the null hypothesis that advertising has no effect on sales. There is sufficient evidence that advertising increases expected sales on average, holding price constant."

B.4 Joint Hypothesis F-test (Restricted vs Full Model)

A t-test handles one parameter at a time. Often we want to test whether a group of variables jointly matters — e.g., "do three dummies representing education level together explain wages?" For this we need the joint F-test.

The logic of the joint F-test
  • Full model: includes all k predictors.
  • Restricted model: the full model with J of the variables removed (their coefficients forced to zero).
  • If the J restrictions are true (those variables really don't matter), the restricted model fits nearly as well → SSE increases only a little.
  • If the restrictions are false, forcing those coefficients to zero hurts fit badly → SSE increases sharply.
  • The F-statistic measures how much SSE increases relative to the residual noise level.
Joint F-test — Two Equivalent Formulas

Via SSE:

F = [(SSEᵣ − SSE) / J] / [SSE / (n − k − 1)]

Via R² (algebraically identical):

F = [(R² − R²ᵣ) / J] / [(1 − R²) / (n − k − 1)]

Under H₀ (all J restrictions hold): F ~ F(J, n − k − 1)

  • J = number of restrictions = number of parameters set to zero (numerator df).
  • n − k − 1 = residual df of the full model (denominator df).
  • Always right-tailed: reject H₀ when F is large.
Why is the F-test always one-tailed (right-tailed)?

Because the F-statistic is a ratio of squared quantities — it is always non-negative. Large F means the restrictions cause a big increase in SSE (bad fit with restrictions → restrictions are false). Small F means the restrictions barely hurt fit (restrictions plausible). We only ever reject in the right tail.

Important Special Cases

Special caseWhat it becomes
J = 1 (testing a single coefficient) The joint F-test is equivalent to the t-test: F = t². The two-sided t-test critical value tₓ satisfies tₓ² = Fₓ.
J = k (testing ALL slopes simultaneously, i.e. H₀: β₁ = β₂ = … = βₖ = 0) F = (SSR/k) / (SSE/(n−k−1)) = MSR / MSE. This is identical to the ANOVA F-test of Chapter C.
Example — Testing Education Dummies Jointly

Suppose diploma has 4 levels (PhD, Master, Bachelor, High school) → 3 dummies. You want to test: "Does diploma level matter at all?"

  • H₀: β_PhD = β_Master = β_Bachelor = 0 (J = 3 restrictions)
  • H₁: at least one of those coefficients ≠ 0
  • Compute F using the SSE formula with J = 3 and df_denom = n − k − 1.
  • Note: even if each individual t-test is non-significant (possible due to multicollinearity among the dummies), the joint F-test might still reject H₀.
SPSS — Running the Joint F-test (Block Method)
  1. Open Analyze → Regression → Linear.
  2. In the Independent(s) panel, enter your restricted-model variables in Block 1.
  3. Click Next to add a second block; enter the additional variables you want to test in Block 2.
  4. Click Statistics and tick R squared change.
  5. In the Model Summary output, read the F Change, df1 (= J), df2, and Sig. F Change for Block 2. This is your joint F-test result.
How to report the F-test result on the exam
  1. State H₀ and H₁ in both words and symbols.
  2. Compute (or read from SPSS) F and give the df pair (J, n−k−1).
  3. State the critical value Fₓ or the p-value.
  4. Conclude in plain language: "We reject H₀ at the 5% level. As a group, the education dummies explain a statistically significant share of the variation in wages."

Goodness of fit asks: how much of the variation in Y is explained by the regression model? The entire chapter flows from a single algebraic identity.

C.1 ANOVA Table — Decomposition of Variance
The Fundamental Decomposition Identity
SST = SSR + SSE
TermFull nameFormulaWhat it measures
SST Total Sum of Squares Σ(yᵢ − ȳ)² Total variation of Y around its sample mean — what we want to explain. Fixed by the data.
SSR Regression (Explained) Sum of Squares Σ(ŷᵢ − ȳ)² Variation explained by the regression model. Increases as the model improves.
SSE Error (Residual) Sum of Squares Σ(yᵢ − ŷᵢ)² Variation not explained — the residuals. OLS minimises this directly.
Why does SST = SSR + SSE hold exactly?

Write yᵢ − ȳ = (ŷᵢ − ȳ) + (yᵢ − ŷᵢ) — the deviation from the mean is the sum of the predicted deviation plus the residual. Squaring both sides and summing over all observations, the cross-product term ΣeᵢŷᵢΣ vanishes (one of the OLS normal equations guarantees that Σeᵢŷᵢ = 0). This is not an approximation — it is an exact algebraic identity that holds for any OLS regression with an intercept.

Reading the ANOVA table
  • Degrees of freedom: n − 1 = k + (n − k − 1). The total df split exactly between regression and residual, just like the sums of squares.
  • MSE = s²: The mean square error is exactly the same as the variance estimate from B.1. The ANOVA table re-uses the same quantity — nothing new to compute.
  • Mean squares are NOT additive: MST ≠ MSR + MSE (only the SS and df are additive). Don't try to add mean squares.
C.2 ANOVA F-test for Model Significance
ANOVA F-test for overall model significance

H₀ : β₁ = β₂ = … = βₖ = 0 (no predictor explains Y — the model is useless)

H₁ : at least one βᵢ ≠ 0 (the model explains something)

F = MSR / MSE = [SSR / k] / [SSE / (n − k − 1)]   ~   F(k, n − k − 1) under H₀
  • Right-tailed test: reject H₀ when F is large.
  • In SPSS: read the F and Sig. columns in the row labelled "Regression" in the ANOVA table.
Connection to the joint F-test (B.4)

The ANOVA F-test is the special case of the joint F-test where J = k (all slopes are tested simultaneously). The restricted model becomes "intercept only" (ŷ = b₀ = ȳ for every observation), so SSER = SST and R²R = 0. Substituting into the joint F formula gives exactly F = MSR / MSE — the ANOVA F.

Common confusions about the ANOVA F-test
  • Significant ANOVA F ≠ every variable is significant. It only means at least one of the βᵢ ≠ 0. Use individual t-tests to identify which ones.
  • Non-significant ANOVA F → stop. If the overall model explains nothing, the individual t-tests and R² are meaningless — you are mining noise.
  • High F does not imply high R². They are related but measure different things: F tests significance; R² measures the proportion explained.
C.3 R² and Adjusted R²
R² — Coefficient of Determination
R² = SSR / SST = 1 − SSE / SST
  • Range: 0 ≤ R² ≤ 1.
  • Interpretation: R² × 100% of the total variation in Y is explained by the regression model.
  • In multiple regression, R² also equals the square of the Pearson correlation between the observed Y and the fitted values Ŷ: R² = [Corr(Y, Ŷ)]².
  • R² = 0: the model explains nothing (all SSR = 0).
  • R² = 1: perfect fit (all observations exactly on the regression surface; SSE = 0).

Why R² Alone Is Not Enough

The R² problem — it never falls when you add variables

Adding any new variable — even a purely random column of numbers — can only maintain or increase R². Why? Because OLS minimises SSE over the expanded parameter space; the old coefficients remain available and the new variable just provides more freedom to reduce SSE further.

Consequence: if you use "maximise R²" as your model-selection rule, you will always choose the model with the most variables, regardless of whether they make economic sense. This is overfitting.

Adjusted R² — Penalising Model Complexity
R̄² = 1 − [SSE / (n − k − 1)] / [SST / (n − 1)] = 1 − MSE / (SST / (n − 1))

Equivalently:   R̄² = 1 − (1 − R²) · (n − 1) / (n − k − 1)

How adjusted R² penalises complexity

The numerator MSE = SSE/(n − k − 1) increases when an irrelevant variable is added because df falls (n − k − 1 shrinks) even though SSE barely moves. The denominator SST/(n − 1) is fixed by the data and never changes. Therefore R̄² can fall when a useless variable enters — exactly the behaviour we want for model selection.

Key properties:

  • R̄² can be negative for very poor models (when MSE > SST/(n−1)).
  • R̄² ≤ R² always. They are equal only when k = 0 (intercept only).
  • R̄² loses the "fraction of variation explained" interpretation. Use R² for storytelling; use R̄² for comparing models with different numbers of predictors.
How to use R² and adjusted R² in practice
  • Report R² to tell the audience how well the model fits: "The model explains 72% of the variation in monthly sales."
  • Compare models with different predictors using adjusted R²: prefer the model with higher R̄².
  • Do NOT choose the model based on R² or R̄² alone. Theory, economic logic, and the 4-question test always come first.

D.2 Quasi-Multicollinearity (QMC)

Definition — Exact vs Quasi Multicollinearity

Exact MulticollinearityQuasi-Multicollinearity (QMC)
What it is One predictor is a perfect linear combination of the others. One predictor is strongly but not perfectly linearly related to the others.
Consequence A4 fails completely. (X'X) matrix is singular — OLS cannot be computed at all. OLS can be computed, but se(Bᵢ) blow up. Estimates are unbiased but imprecise.
Example Including both a variable and its exact negative. Forgetting to drop one dummy (the dummy variable trap). Including both household income and household spending (strongly correlated). Adding x, x², x³ without centering.

Consequences of QMC

The classic QMC fingerprint — the "frustrating combination"
  • Standard errors of affected coefficients blow up → t-ratios shrink → individual t-tests become non-significant.
  • Yet R² and the ANOVA F-test can still be large and significant (the variables jointly explain Y, even if we can't separate their individual effects).
  • Estimates are unbiased in expectation — but highly sensitive to small changes in the data. Adding or removing one observation can flip a sign.
  • Prediction is unaffected as long as new observations have the same correlational structure as the sample.
Why does correlation among predictors inflate se(Bᵢ)?

Intuitively: if x₁ and x₂ always move together, it is impossible to tell which one is driving Y. The data do not give us enough independent variation in each predictor to pin down their separate effects. Mathematically, Var(bᵢ) ∝ 1/(1 − Rᵢ²), where Rᵢ² is how well xᵢ is explained by the other predictors. As Rᵢ² → 1, Var(bᵢ) → ∞.

Detection — VIF and Tolerance

VIF (Variance Inflation Factor) for predictor xᵢ
VIFᵢ = 1 / (1 − Rᵢ²)   ;   Tolerance = 1 / VIFᵢ = 1 − Rᵢ²

where Rᵢ² is obtained by regressing xᵢ on all the other predictors.

VIF valueToleranceSeverity
VIF = 11.0No collinearity — xᵢ is uncorrelated with all other x's.
1 < VIF ≤ 50.2–1.0Mild — generally acceptable.
5 < VIF ≤ 100.1–0.2Moderate — investigate further.
VIF > 10< 0.1Severe — take action (see remedies below).

Some textbooks use the threshold VIF > 5 as the warning level. This course uses VIF > 5 (tolerance < 0.2) as the rule of thumb.

Pairwise correlations are not enough

High pairwise correlation between two predictors is a warning sign, but QMC can arise from multivariate relationships: three predictors may each have moderate pairwise correlations, yet together be nearly perfectly collinear. VIF catches this; pairwise correlations do not.

Five Possible Remedies for QMC

Remedies — ordered from least to most disruptive
  1. Do nothing — if the model's predictions and the joint F-test serve your purpose, and you don't need reliable individual t-tests, QMC may be tolerable. The joint F-test is unaffected by QMC.
  2. Drop a redundant variable — keep the predictor that theory supports best. Check that the remaining estimates are stable and their signs make sense.
  3. Combine or transform — replace two highly correlated x's with a composite (their sum, average, ratio, or difference). E.g. replace both husband's and wife's income with total household income.
  4. Collect more data — a larger n increases the variation in each xᵢ and lowers se(Bᵢ). Not always feasible.
  5. For dummy/interaction QMC:
    • Choose a large reference category for dummies.
    • Centre quantitative variables before creating interaction or polynomial terms: use (xᵢ − x̄) instead of xᵢ. This dramatically reduces the correlation between xᵢ and xᵢ².
SPSS — Getting VIF and Tolerance

Analyze → Regression → Linear → Statistics: tick Collinearity diagnostics. Click Continue and run the regression. VIF and Tolerance appear in the rightmost columns of the Coefficients table.

D.3 Heteroskedasticity

Definition

Homoskedasticity vs Heteroskedasticity

Homoskedasticity (A2 holds): Var(εᵢ) = σ² for every observation. The spread of errors is the same regardless of the values of the predictors. Think: uniform bands around the regression surface.

Heteroskedasticity (A2 fails): Var(εᵢ) = σᵢ² varies across observations — typically growing with the size of Y, with the size of one or more x's, or with the value of a grouping variable.

Common sources:

  • Cross-sectional data where units differ greatly in scale (large vs small firms, rich vs poor households).
  • Richer people have more discretionary income → more variance in their spending decisions.
  • A missing variable whose effect grows with the level of xᵢ.

Consequences of Heteroskedasticity

What heteroskedasticity does to OLS
  • OLS estimates remain unbiased — the estimates b₀, b₁, …, bₖ are still centred on the true β's. A1 is intact; only A2 fails.
  • OLS is no longer BLUE — it is possible to find a more efficient estimator (weighted least squares) that uses the knowledge of which observations are more reliable.
  • The standard errors reported by SPSS are WRONG — they can be either too small (overstating precision) or too large (understating it). Consequently, t-tests and F-tests and confidence intervals are all misleading.
  • Practical conclusion: "My t-test looks significant, but with heteroskedasticity the reported se is unreliable — the true significance may be different."

Detection — Visual Check + the White Test

Step 0 — Visual check: Look at the residual plot (eᵢ vs ŷᵢ or vs xᵢ). Heteroskedasticity typically shows as a fan shape (residuals spread out as ŷᵢ increases) or a funnel shape (residuals narrow as ŷᵢ increases).

White Test — 3 Steps

Step 1. Fit the original regression and save the (unstandardised) residuals eᵢ.

Step 2. Run the auxiliary regression of eᵢ² on: all original predictors, their squares, and all pairwise cross-products:

eᵢ² = α₀ + α₁x₁ᵢ + … + αₖxₖᵢ + β₁x₁ᵢ² + … + βₖxₖᵢ² + γ₁x₁ᵢx₂ᵢ + … + γₘx(ₖ₋₁)ᵢxₖᵢ + u

Step 3. Obtain R² from the auxiliary regression. The test statistic is:

W = n · R²_aux   ~   χ²(number of non-intercept regressors in Step 2) under H₀
  • H₀ : homoskedasticity. Reject H₀ when W is large (right-tailed).
  • p-value rule: reject when p < α.
Why does the White test work?

Under homoskedasticity, eᵢ² should be unrelated to any of the x's — the squared residuals (which proxy σᵢ²) should be random noise, so the auxiliary R² should be near zero. If eᵢ² is systematically related to the x's (R² is large), it means the error variance is varying with the predictors → heteroskedasticity. The chi-squared distribution for n·R² comes from the result that nR² is asymptotically χ² under H₀.

Number of non-intercept regressors in the auxiliary regression for k = 2 predictors: 2 main effects + 2 squares + 1 cross-product = 5 df.

SPSS — White Test by Hand
  1. Run the original regression with Save → Unstandardised residuals (stored as RES_1).
  2. Transform → Compute Variable: create SqRes = RES_1 ** 2.
  3. Create the squared predictors and cross-products: e.g. X1sq = X1 ** 2, X2sq = X2 ** 2, X1X2 = X1 * X2.
  4. Run a new regression with SqRes as the dependent variable and all of {X1, X2, X1sq, X2sq, X1X2} as predictors.
  5. Read R² from the Model Summary. Compute W = n × R². Compare W to χ²-critical with df = 5 (for k = 2), or read the p-value from a χ² table.

Four Common Remedies for Heteroskedasticity

Remedies — from easiest to most advanced
  1. Look for an omitted variable. Heteroskedasticity sometimes disappears once the missing variable is included. The varying error spread was really the omitted variable's effect masquerading as noise.
  2. Transform the dependent variable (log). A log transformation on Y often stabilises variance because it compresses the scale for large values. The double-log model (ln Y = β₀ + β₁ ln x + …) is particularly effective when both Y and x span several orders of magnitude.
  3. Use relative variables. Divide Y and/or x's by a "scale variable" (e.g. firm size, income) to put observations on a comparable scale. This removes a common source of variance growth.
  4. Weighted Least Squares (WLS) or Robust Standard Errors (HC se's). WLS re-weights observations so that noisier ones count less. Robust (Huber–White) standard errors keep the OLS estimates but correct the se's for heteroskedasticity — available in SPSS via Analyze → Regression → Linear → Options → Heteroskedasticity-consistent (not in all versions) or via syntax.
Specify → Estimate → Judge → Validate … and iterate.

If validation (Chapter D) finds a problem — quasi-multicollinearity, heteroskedasticity, a wrong functional form, or an omitted variable — go back to Chapter A and re-specify. A good model is never the result of one regression run. It is the product of a thoughtful, theory-anchored loop.
